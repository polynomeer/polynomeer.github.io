# polynomeer.github.io

복잡한 문제를 구조와 정책으로 정리해 기록하는 기술 블로그 저장소다.

## 블로그 소개

이 블로그는 다음 주제를 중심으로 글을 쌓아 간다.

- Java와 Spring 기반 백엔드 개발
- 시스템 아키텍처와 성능 최적화
- 배치 처리와 대용량 데이터 처리
- 이벤트 기반 시스템과 메시지 큐
- DevOps, CI/CD, 관측성

## 기술 스택

정적 사이트는 Jekyll 기반으로 운영한다.

- Jekyll
- GitHub Pages
- SCSS 커스터마이징
- Markdown 기반 포스팅

## 디렉터리 구조

```text
├── _posts/            # 블로그 포스트
├── _layouts/          # HTML 레이아웃
├── _includes/         # 재사용 가능한 HTML 조각
├── assets/            # 이미지와 정적 리소스
├── _config.yml        # Jekyll 설정
└── README.md
```

## 로컬 개발

```bash
bundle install
bundle exec jekyll serve
```
