## 컬렉션과 문자열

### ArrayList.remove() - 값 삭제

`ArrayList.remove()`는 두 가지로 오버로딩되어 있다. `remove(int index)`는 지정한 위치의 원소를 지우고, `remove(Object o)`는 지정한 원소가 처음 나타나는 곳을 지운다.

### ArrayList 정렬

정렬 조건이 여러개인 경우

정렬 조건이 여럿이면 `Comparator`를 이어 붙인다. `Comparator.thenComparing()`은 첫 번째 비교자로 같다고 판단된 원소를 두 번째 비교자로 다시 비교하는, 사전 순서(lexicographic-order) 비교자를 돌려준다.

### enum

우아한형제들 글은 enum으로 상태와 행위를 한곳에서 관리하는 예를 보여 준다. 상수마다 계산식을 따로 가져야 할 때 static 메서드를 흩어 두는 대신 enum 상수에 계산식을 함께 둔다. `ordinal()`에 의존하면 상수가 중간에 추가될 때 숫자가 가리키는 상수가 바뀌므로 피해야 한다는 점도 짚는다.

### String immutable 객체

`String` Javadoc은 문자열을 상수로 설명한다. 한 번 만들어진 `String`의 값은 바꿀 수 없다.

### String 이어붙이기

문자열을 붙이는 방법은 `+` 연산자, `concat()`, `StringBuilder.append()` 세 가지다. 참고한 글에 따르면 대부분은 `+`를 쓰고, 상황에 따라 `append()`를 쓴다.

### StringTokenizer

StringTokenizer to String

`StringTokenizer`로 나눈 토큰을 다시 문자열로 합치는 방법을 찾았다.

## 파일과 입출력

### 파일입출력

`BufferedReader`의 `readLine()`으로 파일을 한 줄씩 읽을 수 있다. `readLine()`은 줄 끝의 개행 문자를 포함하지 않고 돌려준다.

### 자바 경로 얻어내기

현재 작업 디렉터리는 시스템 프로퍼티 `user.dir`에 들어 있어 `System.getProperty("user.dir")`로 읽을 수 있다.

### 자바 줄바꿈 문자

줄바꿈 문자는 운영체제마다 다르다. `System.lineSeparator()`는 시스템에 맞는 줄 구분 문자열을 돌려준다.

### 자바 키보드 입력

키보드 입력은 `Scanner`를 쓰거나 `System.in`을 `BufferedReader`로 감싸 읽는다. 참고한 글은 두 방식의 차이를 사용 편의성으로 보고, `Scanner`가 더 나중에 나온 클래스라고 정리한다.

## 셸과 프로세스

### 자바 코드로 쉘 명령어 실행하기, 자바 프로세스 생성

Java에서 외부 프로세스는 `Runtime.exec()`나 `ProcessBuilder`로 만든다. `ProcessBuilder`는 운영체제 프로세스를 만드는 클래스다. NAVER D2 글은 서브 프로세스의 표준 출력 스트림을 실행과 동시에 읽어야 한다고 강조한다. 일부 플랫폼은 표준 입출력 버퍼가 작아서, 스트림을 제때 비우지 않으면 서브 프로세스가 멈추거나 교착 상태에 빠질 수 있다.

### 쉘 만들기

C로 간단한 셸을 만드는 예제와, 리눅스 커널의 `init/main.c`, MINT64 OS의 콘솔 셸 소스, 고급 Bash 스크립팅 가이드를 모아 두었다.

## Git

`git push`에서 `fatal: The current branch master has no upstream branch.`가 나면 원격 저장소와 브랜치를 지정해야 한다. 에러 메시지가 안내하는 대로 `git push --set-upstream origin master`로 업스트림을 설정한다.

좋은 git 사용 습관 글은 `git add .`와 `git commit -m` 두 명령으로만 커밋하는 습관을 좋지 않다고 본다. 커밋 전에 `git status`로 추적 중인 파일과 새로 추가된 파일을 확인하고, 필요 없는 파일은 `.gitignore`에 넣으라고 권한다.

### 스프링 사용목적

참고한 글은 Spring의 특징을 DI(Dependency Injection)부터 설명한다. 한 클래스가 다른 클래스를 직접 생성해 쓰면 둘 사이에 의존성이 생기고, Spring은 이 의존성을 외부에서 주입해 준다.

### 오버로딩 vs 오버라이딩

메서드 시그니처는 메서드를 구분하는 역할을 한다. 오버로딩은 같은 이름으로 시그니처(매개변수 목록)가 다른 메서드를 여러 개 정의하는 것이고, 오버라이딩은 상위 클래스의 메서드를 같은 시그니처로 하위 클래스에서 다시 정의하는 것이다. 매개변수 이름은 시그니처에 포함되지 않는다.
