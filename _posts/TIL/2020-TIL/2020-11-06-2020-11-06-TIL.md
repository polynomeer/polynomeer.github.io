# 2020-11-06-TIL

### github.io 개설

코드스쿼드의 알고리즘 추천 문제들을 풀어가다가 TIL의 필요성을 느껴서 시작하게 되었다. 그 작성 플랫폼으로는 github.io를 선택하였다.

GitHub Pages는 저장소에 올린 파일을 정적 사이트로 호스팅해 주는 서비스이고, Jekyll을 기본 정적 사이트 생성기로 지원한다. 마크다운으로 글을 쓰고 커밋하면 GitHub가 HTML로 빌드해서 `<사용자명>.github.io` 주소로 배포한다. 서버를 따로 운영하지 않아도 되고, 글이 곧 저장소의 커밋 이력으로 남는다는 점이 TIL 플랫폼으로 잘 맞는다.

테마를 적용하는 방법은 두 가지다. 테마 저장소를 통째로 포크해서 쓰는 방법과, `_config.yml`에 `remote_theme: 소유자/저장소` 형태로 적어 다른 저장소의 테마를 원격으로 가져오는 방법이다. 두 번째 방법은 `jekyll-remote-theme` 플러그인이 처리하며, GitHub Pages 문서도 이 방식으로 공개 저장소의 테마를 쓸 수 있다고 안내한다. 포크 방식은 테마를 마음대로 고치기 쉽고, 원격 테마 방식은 내 저장소에 글과 설정만 남아 깔끔하다.

### Lv.1

입출력과 반복문, 문자열 처리를 확인하는 기초 문제들이다.

- 1000(A+B), 1008(A/B): 표준 입력을 읽고 계산해 출력하는 가장 기본적인 문제다. 1008은 나눗셈 결과를 실수로 출력해야 해서, 정수 나눗셈과 부동소수점 오차 허용 범위를 의식하게 된다.
- 2438(별 찍기): 중첩 반복문으로 줄마다 별 개수를 늘려 출력한다.
- 2920(음계): 입력 수열이 오름차순인지, 내림차순인지, 둘 다 아닌지 판별한다. 인접한 두 값의 차이만 보면 된다.
- 8958(OX퀴즈): 연속된 O의 개수를 누적하며 점수를 더한다. 연속 구간을 셀 때 상태 변수 하나를 두는 패턴을 연습할 수 있다.
- 11654(아스키 코드): 문자를 정수로 바꿔 코드 값을 출력한다. Java에서는 `char`를 `int`로 캐스팅하면 된다.
