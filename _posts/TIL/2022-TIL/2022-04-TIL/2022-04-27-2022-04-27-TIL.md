## Today I Learned

### Music App Open Sources

GitHub의 음악 플레이어 오픈소스 프로젝트를 모았다. 대부분 Android 앱이다. 저장소 설명, 언어, 라이선스, 보관 여부는 나중에 GitHub에서 다시 확인한 상태를 기준으로 적었다. 보관(archived) 상태인 저장소는 더 이상 유지 보수되지 않으므로 코드 구조를 참고하는 용도로만 보는 편이 맞다.

| 저장소 | 설명(저장소 소개 기준) | 언어 | 비고 |
| --- | --- | --- | --- |
| ryanhoo/StylishMusicPlayer | Android 기기(16+)용 음악 플레이어 | Java | |
| Mpmart08/MusicPlayer | JavaFX/Java 8로 만든 Windows, Mac용 데스크톱 음악 플레이어 | Java | archived, MIT |
| andremion/Music-Player | UI 제안 디자인을 코드로 옮긴 프로젝트 | Java | Apache-2.0 |
| timusus/Shuttle | Shuttle 음악 플레이어 | Java | archived |
| iammert/MusicPlayerView | 음악 플레이어용 Android 커스텀 뷰와 진행 표시 | Java | |
| hefuyicoder/ListenerMusicPlayer | Material Design 음악 플레이어 | Java | |
| kabouzeid/Phonograph | Material Design 기반 Android 음악 플레이어 | Java | archived, GPL-3.0 |

볼 때 주의할 점은 두 가지다.

- 라이선스가 다르다. Apache-2.0과 MIT는 조건을 지키면 상용 코드에 가져다 쓰기 비교적 자유롭지만, GPL-3.0인 Phonograph의 코드를 가져다 쓰면 내 앱도 GPL 조건을 따라야 한다. 라이선스가 표시되지 않은 저장소는 코드를 복사하지 말고 구조만 참고한다.
- 보관된 저장소는 최신 Android 버전의 변경 사항을 반영하지 않는다. 백그라운드 재생이나 알림 컨트롤처럼 플랫폼 정책에 묶인 부분은 그대로 따라 하기보다 구조를 이해하는 데 쓴다.

Phonograph 저장소는 지금 `karimknaebel/Phonograph`로 옮겨져 있고, 기존 주소로 접속하면 이동한다.
