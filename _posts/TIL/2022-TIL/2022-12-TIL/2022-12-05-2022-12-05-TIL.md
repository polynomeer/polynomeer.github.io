### WAV File Format Specification

WAV는 Microsoft의 RIFF(Resource Interchange File Format) 컨테이너 위에 정의된 오디오 포맷이다. 파일은 `RIFF` 헤더로 시작하고 형식 이름 `WAVE`가 뒤따르며, 그 안에 오디오 형식을 기술하는 `fmt ` 청크와 실제 샘플이 담긴 `data` 청크가 들어 있다. 보통 비압축 PCM을 담기 때문에 MP3보다 파일이 크다.

`fmt ` 청크에는 오디오 포맷 코드(PCM은 1), 채널 수, 샘플레이트, 초당 바이트 수(ByteRate), 샘플 하나의 바이트 수(BlockAlign), 샘플당 비트 수가 들어 있다. 그래서 PCM WAV의 재생 시간은 `data` 청크 크기를 ByteRate로 나누면 바로 구할 수 있다. 다만 `LIST` 같은 부가 청크가 끼어 있는 파일도 있으므로 헤더를 고정 44바이트로 가정하지 말고 청크 ID와 크기를 따라가며 읽는 편이 안전하다.

### MP3 File Format Specification

MP3(MPEG-1/2 Audio Layer III)는 손실 압축 포맷이다. 파일 앞이나 뒤에 ID3 태그로 제목, 아티스트 같은 메타데이터가 붙을 수 있고, 본문은 독립적인 프레임의 연속이다. 각 프레임은 11개의 1비트로 된 동기 패턴으로 시작하는 헤더를 가지며, 헤더에 MPEG 버전, 레이어, 비트레이트 인덱스, 샘플레이트 인덱스가 들어 있다.

재생 시간 계산이 WAV보다 까다로운 이유가 여기에 있다. 고정 비트레이트(CBR) 파일은 파일 크기를 비트레이트로 나눠 근사할 수 있지만, 가변 비트레이트(VBR) 파일은 프레임마다 비트레이트가 달라 이 방식이 맞지 않는다. 정확한 값을 얻으려면 모든 프레임을 훑으며 프레임별 재생 시간을 더하거나, VBR 인코더가 첫 프레임에 넣어 두는 `Xing` 헤더(총 프레임 수 등 파일 전체 정보)를 읽어야 한다. mp3inside 문서는 이 문자열이 없으면 CBR 파일로 간주한다고 설명한다.

### Java Sound API

> What audio formats does Java Sound support?
Java Sound supports the following audio file formats: AIFF, AU and WAV. It also supports the following MIDI based song file formats: SMF type 0 (Standard MIDI File, aka .mid files), SMF type 1 and RMF.

MP3 등 여러가지 압축 포맷은 지원하지 않는다.

`javax.sound.sampled`의 `AudioFileFormat`은 선택적인 프로퍼티로 `"duration"`(마이크로초 단위 `Long`)을 정의하지만, 파일 리더 구현이 이 값을 반드시 채워야 하는 것은 아니다. WAV라면 `AudioInputStream`의 프레임 수를 프레임레이트로 나눠 직접 계산하는 편이 확실하다.

```java
try (AudioInputStream in = AudioSystem.getAudioInputStream(file)) {
    AudioFormat format = in.getFormat();
    double seconds = in.getFrameLength() / format.getFrameRate();
}
```

MP3는 기본 API로 열리지 않으므로 별도 SPI 구현이나 메타데이터 라이브러리, 또는 앞에서 본 `ffprobe`를 써야 한다. 아래 링크의 Stack Overflow 답변들도 대부분 이 세 갈래 중 하나를 권한다.

### JPA Column Default Value

엔티티에서 값을 채우지 않은 필드는 `null`로 INSERT 문에 포함되기 때문에, DDL에 `DEFAULT`를 걸어 두어도 적용되지 않는 경우가 생긴다. 기본값을 주는 방법은 대략 네 가지다.

- 필드 초기값: `private Status status = Status.READY;`처럼 자바 쪽에서 값을 정한다. 가장 단순하고 DB와 무관하다.
- `@Column(columnDefinition = "...")`, Hibernate의 `@ColumnDefault`: 스키마 생성 시 DDL에 DEFAULT를 넣는다. INSERT에 `null`이 들어가면 여전히 기본값이 적용되지 않는다.
- Hibernate `@DynamicInsert`: `null`인 컬럼을 INSERT 문에서 빼서 DB 기본값이 적용되게 한다. 엔티티마다 SQL을 동적으로 만든다는 비용이 있다.
- `@PrePersist` 콜백에서 비어 있는 값을 채운다.
