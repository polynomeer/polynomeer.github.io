## Spring Scheduler

Spring은 주기적으로 실행할 작업을 애너테이션으로 등록하는 기능을 제공한다. 설정 클래스에 `@EnableScheduling`을 붙이면 빈의 메서드에 붙은 `@Scheduled`가 동작하기 시작한다. 이 애너테이션이 없으면 `@Scheduled`를 붙여도 아무 일도 일어나지 않는다.

```java
@Configuration
@EnableScheduling
public class SchedulingConfig {
}

@Component
public class ReportJob {

    @Scheduled(fixedDelay = 5000)
    public void run() {
        // 이전 실행이 끝나고 5초 뒤에 다시 실행
    }
}
```

스케줄 메서드는 반환 타입이 `void`이고 인자를 받지 않아야 한다. 필요한 객체는 파라미터가 아니라 빈 주입으로 받는다. 주기를 정하는 방법은 `fixedDelay`, `fixedRate`, `cron` 세 가지인데, 각 옵션의 차이는 다음 TIL에서 이어서 정리했다.

- https://javafactory.tistory.com/1386

## AI 키워드: TruthfulQA

언어 모델이 사람들이 흔히 믿는 잘못된 상식을 그대로 따라 말하는지 측정하는 TruthfulQA 벤치마크가 공개됐다. 건강, 법, 금융, 정치 등 38개 분야의 질문 817개로 구성되어 있다. 논문에 따르면 가장 좋은 모델이 58%의 질문에 진실하게 답했고 사람은 94%였으며, 큰 모델일수록 오히려 덜 진실한 경향이 있었다.
