### [Using Java 8 Streams replace Characters in a String if found in a list of Characters](https://stackoverflow.com/questions/47204693/using-java-8-streams-replace-characters-in-a-string-if-found-in-a-list-of-charac)

문자열을 스트림으로 다루려면 `String.chars()`로 `IntStream`을 얻어 각 문자를 코드 값으로 처리한 뒤 다시 모은다. 특정 문자 목록에 들어 있는 문자를 바꾸는 경우라면 목록을 `Set<Character>`로 만들어 두고 `map`에서 포함 여부를 검사한다. 다만 단순 치환은 `String.replace()`나 정규식 `replaceAll("[abc]", "")`이 더 짧고 읽기 쉬워서, 스트림은 문자마다 조건이 복잡할 때 쓰는 편이 낫다.

```java
Set<Character> targets = Set.of('a', 'e');
String result = "banana tree".chars()
        .mapToObj(c -> targets.contains((char) c) ? "*" : String.valueOf((char) c))
        .collect(Collectors.joining()); // "b*n*n* tr**"
```

### Java program to convert a Set to an array

`Set`을 배열로 바꾸려면 `set.toArray(new String[0])`처럼 타입이 있는 배열을 넘긴다. 인자 없는 `toArray()`는 `Object[]`를 돌려주므로 캐스팅이 필요하다. 원시 타입 배열(`int[]`)이 필요하면 `set.stream().mapToInt(Integer::intValue).toArray()`를 쓴다.

### Sorting with Comparable and Comparator in Java

`Comparable`은 클래스 스스로 자연 순서를 정의하는 인터페이스로 `compareTo()`를 구현한다. `Comparator`는 클래스 밖에서 정렬 기준을 따로 정의하며 `compare()`를 구현한다. 한 클래스에 정렬 기준이 하나면 `Comparable`, 상황에 따라 여러 기준이 필요하거나 수정할 수 없는 클래스를 정렬해야 하면 `Comparator`를 쓴다. Java 8의 `Comparator.comparing(Person::getAge).thenComparing(Person::getName)`처럼 기준을 조합할 수도 있다.

https://www.infoworld.com/article/3323403/java-challengers-5-sorting-with-comparable-and-comparator-in-java.html

### PriorityQueue in Java

`PriorityQueue`는 우선순위 힙으로 구현된 큐다. 자연 순서(또는 생성자에 넘긴 `Comparator`)상 가장 작은 원소가 머리에 오며, Javadoc에 따르면 `offer`, `poll`, `add`, `remove()`는 O(log n), `peek`은 상수 시간이다. 반복자(iterator)로 순회하면 우선순위 순서가 보장되지 않으므로 정렬된 순서가 필요하면 `poll()`로 하나씩 꺼내야 한다. 최대 힙이 필요하면 `new PriorityQueue<>(Comparator.reverseOrder())`로 만든다.

- https://www.geeksforgeeks.org/priority-queue-class-in-java-2/
- http://asuraiv.blogspot.com/2015/11/java-priorityqueue.html

인쇄 대기열에서 맨 앞 문서보다 중요도가 높은 문서가 뒤에 있으면 맨 앞 문서를 다시 맨 뒤로 보내는 규칙으로, 특정 문서가 몇 번째로 인쇄되는지 구하는 문제다. 대기열은 일반 큐로 두고, 남은 문서 중 최대 중요도는 `PriorityQueue`(최대 힙)로 관리하면 매번 전체를 훑지 않고 비교할 수 있다.

### Combination and Permutation in Java

순열은 n개 중 r개를 순서를 고려해 뽑는 경우, 조합은 순서를 고려하지 않고 뽑는 경우다. 코드로는 재귀와 방문 배열(순열)이나 시작 인덱스(조합)를 넘기는 백트래킹으로 모든 경우를 만든다. 개수만 필요하면 nPr = n! / (n-r)!, nCr = n! / (r!(n-r)!) 공식으로 계산하되, 팩토리얼은 금방 `long` 범위를 넘으므로 파스칼의 삼각형(nCr = n-1Cr-1 + n-1Cr)으로 구하는 편이 안전하다.

https://www.tutorialspoint.com/permutation-and-combination-in-java
