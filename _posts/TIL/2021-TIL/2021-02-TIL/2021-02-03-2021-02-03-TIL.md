### Jekyll 테마가 적용되는 방식

Jekyll 문서에 따르면 테마는 크게 두 가지 방식으로 쓴다. 하나는 gem 기반 테마다. 레이아웃(`_layouts`), 조각(`_includes`), 스타일(`_sass`), 정적 파일(`assets`)을 Ruby gem으로 묶어 배포하므로, 내 저장소에는 그 파일들이 보이지 않는다. 테마 제작자가 새 버전을 RubyGems에 올리면 `bundle update`로 받을 수 있다.

다른 하나는 GitHub Pages가 지원하는 `remote_theme` 설정이다. GitHub에 올라와 있는 테마 저장소를 gem 기반 테마처럼 가져다 쓰는 방식이라, RubyGems에 배포되지 않은 테마도 쓸 수 있다.

```yaml
# _config.yml
theme: minima                       # gem 기반 테마
# remote_theme: owner/repo-name     # GitHub Pages의 원격 테마
```

### 테마 일부만 바꾸기

마음에 드는 테마를 골라도 조금씩 고치고 싶어진다. Jekyll은 테마 파일보다 내 사이트의 파일을 먼저 찾는다. 그래서 테마에 `page` 레이아웃이 있을 때 내 저장소의 `_layouts`에 같은 이름의 파일을 만들면 그 파일이 대신 쓰인다. `_includes`, `_sass`, `_data`, `assets`도 같은 방식으로 덮어쓸 수 있다.

다만 문서는 테마 파일을 복사해 덮어쓰면 그 파일에 대해서는 테마 업데이트를 받지 못한다고 경고한다. 색상 몇 가지만 바꾸고 싶다면 파일 전체를 복사하기보다 새 스타일 파일에서 필요한 부분만 덮어쓰는 편이 업데이트를 받기에 유리하다.
