## 양의 정수 중 빠진 가장 작은 수 찾기

풀이 코드와 채점 메모로 보아 Codility의 MissingInteger 문제다. 정수 N개로 된 배열 A가 주어질 때 A에 없는 가장 작은 양의 정수를 돌려줘야 한다. 예를 들어 `[1, 3, 6, 4, 1, 2]`이면 5, `[1, 2, 3]`이면 4, `[-1, -3]`이면 1이다. N은 1 이상 100,000 이하이고, 각 원소는 -1,000,000 이상 1,000,000 이하다.

채점 결과에서 메모해 둔 실패 사례는 다음과 같다.

For example, for the input `[-1000000, 1000000]` the solution terminated unexpectedly.

chaotic sequences length=10005 (with minus)

**WRONG ANSWER**, got 0 expected 100001

chaotic + many -1, 1, 2, 3 (with minus)

첫 번째는 음수 최솟값과 양수 최댓값이 함께 들어간 입력에서 실행이 비정상 종료된 경우다. WRONG ANSWER는 답이 100,001이어야 하는 입력, 즉 1부터 100,000까지가 모두 들어 있는 입력에서 0을 돌려준 경우다. N이 최대 100,000이므로 답은 최대 100,001이다. 아래 풀이는 양수만 체크 배열에 표시한 뒤 1부터 차례로 비어 있는 칸을 찾고, 끝까지 다 차 있으면 반복문이 끝난 시점의 `i`를 돌려준다.

```java
class Solution {
    public int solution(int[] A) {
        int[] check = new int[1000001];
        for (int a : A) {
            if (a > 0) check[a] = 1;
        }
        int i = 1;
        for (i = 1; i < 1000001; i++) {
            if (check[i] == 0) return i;
        }
        return i;
    }
}
```
