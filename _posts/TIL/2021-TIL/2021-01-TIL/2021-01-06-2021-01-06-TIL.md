# 2020-01-06-TIL

## Today I Learned

### 자바 문자열 뒤집기

- [jobc.tistory.com/175](https://jobc.tistory.com/175)

Java의 `String`은 불변 객체라서 문자열 자체를 뒤집는 메서드가 없다. 대신 변경 가능한 문자열 버퍼인 `StringBuilder`에 담아 `reverse()`를 부른 뒤 다시 `String`으로 꺼낸다.

```java
String s = "hello";
String reversed = new StringBuilder(s).reverse().toString();  // "olleh"
```

직접 구현한다면 `char` 배열로 바꾼 뒤 양 끝에서 두 포인터를 안쪽으로 옮기며 맞바꾼다. 길이 n인 문자열에서 n/2번 교환하므로 시간 복잡도는 O(n)이다.

```java
char[] chars = s.toCharArray();
for (int i = 0, j = chars.length - 1; i < j; i++, j--) {
    char tmp = chars[i];
    chars[i] = chars[j];
    chars[j] = tmp;
}
String reversed = new String(chars);
```

### 두 방법의 차이: 서로게이트 쌍

두 코드는 영어나 한글에서는 같은 결과를 내지만, 이모지 같은 일부 문자에서 달라진다. Java는 문자열을 UTF-16으로 다루고 `char` 하나는 16비트다. 그래서 코드 포인트가 U+FFFF보다 큰 문자는 `char` 두 개(서로게이트 쌍)로 표현된다. 위의 직접 구현은 `char` 단위로 맞바꾸므로 쌍의 순서까지 뒤집혀 깨진 문자가 된다.

`StringBuilder.reverse()`는 이 경우를 처리한다. Javadoc에 따르면 서로게이트 쌍은 뒤집을 때 하나의 문자로 취급되고, 쌍 안의 high-low 순서는 뒤집히지 않는다. 문제 풀이에서는 입력이 영문이나 숫자로 한정되는 경우가 많아 직접 구현해도 되지만, 실제 사용자 입력을 다룬다면 라이브러리 메서드를 쓰는 편이 안전하다.

## AI 키워드: T5

2019년 10월 Google 연구진이 T5(Text-to-Text Transfer Transformer) 논문을 arXiv에 올렸다. 번역, 요약, 분류 같은 서로 다른 자연어 처리 작업을 모두 "텍스트를 넣으면 텍스트가 나온다"는 하나의 형식으로 바꿔 같은 모델로 학습시키는 방식이다. 논문은 이 틀 위에서 사전 학습 목표, 모델 구조, 데이터셋 같은 요소를 체계적으로 비교했다.
