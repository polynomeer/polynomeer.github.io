# 2021-01-13-TIL

## JDK 소스코드 열어보기

`ArrayList`가 내부에서 배열을 어떻게 늘리는지, `HashMap`이 충돌을 어떻게 처리하는지는 문서보다 소스를 직접 보는 편이 빠를 때가 있다. JDK는 표준 라이브러리 소스를 함께 배포하므로 따로 내려받지 않아도 된다.

---

### IntelliJ 에서 열어보기

아무 프로젝트나 생성해서 찾고자하는 라이브러리를 import한다.

```
import java.util.ArrayList;
```

그리고 command + 왼쪽마우스 클릭을 하면 자동으로 External Library로 부터 소스코드가 펼쳐지면서 보인다.

IntelliJ 문서에서는 이 동작을 Go to Declaration이라고 부르고, 단축키는 macOS에서 `Cmd+B`다. 커서를 클래스나 메서드 이름에 두고 누르면 선언부로 이동한다. JDK 클래스라면 프로젝트에 설정된 JDK의 소스로 이동하는 것이다.

---

### JDK 경로로 직접 찾아가기

- macOS

  /Library/Java/JavaVirtualMachines/jdk-version.jdk/Contents/Home/lib

  해당 경로에 들어가면 src.zip 파일이 포함되어있다. 그 파일의 압축을 풀면 jdk 및 자바 라이브러리의 전체 소스코드를 확인할 수 있다.

Oracle의 JDK 11 설치 문서도 설치 디렉터리 구조에서 `lib/src.zip`을 "The archive that contains the source code for the Java platform"이라고 설명한다. 위치는 버전에 따라 다르다. JDK 9 문서에서는 `src.zip`이 `lib` 아래가 아니라 설치 루트 디렉터리에 있다고 적혀 있다. 그래서 다른 버전에서 파일이 안 보이면 설치 루트도 확인해 본다.
