# 2021-05-12-TIL

## Git에서 파일이름 대소문자 변경 반영하기
- https://musma.github.io/2019/03/04/git-force-file-rename.html

macOS의 기본 파일 시스템이나 Windows의 NTFS는 대소문자를 구분하지 않는다. Git은 `git init`이나 `git clone` 때 파일 시스템을 검사해서 이런 환경이면 `core.ignoreCase`를 `true`로 둔다([git-config](https://git-scm.com/docs/git-config#Documentation/git-config.txt-coreignoreCase)). 그래서 `Item.java`를 `item.java`로 바꿔도 Git은 같은 파일로 보고 변경을 잡지 않는다. 그런데 리눅스 서버나 CI는 대소문자를 구분하므로, 로컬에서는 빌드되는데 서버에서는 클래스나 파일을 못 찾는 문제가 생긴다.

이름 변경을 Git에 직접 알려 주면 된다. 임시 이름을 한 번 거치면 대소문자를 구분하지 않는 환경에서도 확실하게 반영된다.

```bash
git mv Item.java temp.java
git mv temp.java item.java
```

## 데모 흐름

1. 게임 스타트를 누르면 게임 리스트가 받아와진다.
2. 진행중인 게임에 대해서는 선택이 안되도록 했습니다.
3. 그러면 첫번째 팀을 선택하고 player표시가 뜨고
4. 마우스로 상단의 버튼을 슬라이드하면 스코어 현황판이뜨고
5. 아래쪽을 슬라이드하면 선수별 스코어 현황판이 보입니다.
6. 그리고 PITCH버튼을 누르면, 일정 비율에 따라 strike, ball, 안타가 결정되고,
7. 4 ball이면 진루, 3 strike 면 아웃이 됩니다.
8. 옴팡이가 홈에 들어오면 점수가 올라갑니다.

## AI 키워드: 확산 모델

2021년 5월 11일 arXiv에 "Diffusion Models Beat GANs on Image Synthesis" 논문이 올라왔다. 노이즈를 조금씩 걷어 내며 이미지를 만드는 확산 모델(diffusion model)이 ImageNet 이미지 생성 품질 지표에서 당시 최고 수준이던 GAN을 앞섰다는 결과다. 분류기의 기울기로 생성 방향을 조절하는 classifier guidance도 함께 제안했다.
