## Today I Learned

### AI 키워드: StableCode

8월 8일 Stability AI가 코드 생성용 언어 모델 StableCode를 발표했다. 지금은 Stable Code Alpha라는 이름으로 페이지가 갱신되어 있다([Stability AI 발표](https://stability.ai/news-updates/stablecode-llm-generative-ai-coding)). 30억 파라미터 크기이고, 용도에 따라 세 가지 모델로 나뉜다.

- 기본 모델: The Stack 데이터셋(v1.2)의 여러 프로그래밍 언어 코드 5,600억 토큰으로 학습했다.
- 지시 모델: 기본 모델을 코드 질문과 답변 쌍 약 12만 개로 추가 학습해서, 자연어 요청을 받아 코드를 쓰도록 맞췄다.
- 긴 컨텍스트 모델: 한 번에 16,000 토큰까지 받는다. 여러 파일을 함께 보여 주고 코드를 만들게 할 때 필요한 길이다.

지원 언어로는 Python, Go, Java, JavaScript, C, C++, Markdown을 든다. 기본 모델을 먼저 만들고 그 위에 지시 모델과 긴 컨텍스트 모델을 얹는 구성은, 코드 자동 완성 도구 뒤의 모델이 어떤 단계를 거쳐 만들어지는지 보여 준다.
