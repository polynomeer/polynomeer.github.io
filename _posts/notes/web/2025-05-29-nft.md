NFT(Non-Fungible Token, 대체 불가능 토큰)는 **디지털 자산의 소유권을 블록체인에 기록하여 증명하는 기술**입니다. '디지털 파일에 대한 유일한 소유권 증명서'라고 생각하면 이해하기 쉽습니다.

---

## 🧠 1. NFT란?

| 항목               | 설명                             |
| ---------------- | ------------------------------ |
| **Non-Fungible** | 대체 불가능, 각각이 고유한 자산 (비트코인과는 다름) |
| **Token**        | 블록체인 위에 존재하는 디지털 자산            |
| **주요 특징**        | 희소성, 소유권 추적, 위조 불가, 거래 가능      |

### 🎨 예시

* 디지털 아트: Beeple 작품이 6900만 달러에 낙찰
* 수집품: CryptoPunks, Bored Ape Yacht Club
* 게임 아이템: Axie Infinity, Illuvium
* 음악, 영상, 티켓, 도메인, 부동산까지 확장 가능

---

## 🏗️ 2. NFT의 구조

NFT는 일반적으로 **스마트 컨트랙트**를 통해 발행됩니다.

### 📦 기본 구조 (ERC-721 기준)

* **토큰 ID**: 고유 식별자 (예: `#1234`)
* **메타데이터**: 이름, 이미지, 설명, 속성 등
* **소유자 주소**: 이 NFT를 보유한 지갑 주소

```json
{
  "name": "My NFT",
  "description": "This is a unique item.",
  "image": "https://ipfs.io/ipfs/Qm...",
  "attributes": [
    { "trait_type": "Background", "value": "Blue" },
    { "trait_type": "Eyes", "value": "Laser" }
  ]
}
```

---

## ⚙️ 3. NFT 작동 원리

1. **NFT 발행 (Minting)**

   * 사용자가 스마트 컨트랙트를 통해 NFT 생성
   * 메타데이터는 IPFS 등 분산 스토리지에 저장

2. **NFT 저장**

   * 소유 정보는 블록체인에 저장됨 (지갑 주소 ↔ Token ID)

3. **거래 및 이전**

   * 사용자는 NFT 마켓플레이스(OpenSea, Blur 등)에서 사고팔 수 있음
   * 거래 시 스마트 컨트랙트가 소유권을 이전

4. **검증 가능성**

   * 누구나 블록체인에서 해당 NFT의 소유자와 이력을 확인 가능

## 🔗 4. 주요 표준

| 표준             | 설명                     | 대표                 |
| -------------- | ---------------------- | ------------------ |
| **ERC-721**    | 단일 고유 토큰               | CryptoPunks, BAYC  |
| **ERC-1155**   | 동일한 토큰 여러 개 가능 (반-대체형) | 게임 아이템             |
| **Solana NFT** | Metaplex 사용            | SolSea, Magic Eden |

---

## 🎯 5. NFT의 가치 요소

| 요소   | 설명                    |
| ---- | --------------------- |
| 희소성  | 유일한 ID, 제한된 발행량       |
| 커뮤니티 | BAYC처럼 소유자 전용 커뮤니티 존재 |
| 유틸리티 | 이벤트 참가, 게임 내 사용 등     |
| 이력   | 최초 소유자와 거래 히스토리 추적 가능 |

---

## ⚠️ 6. NFT의 한계와 리스크

* 실물 자산과 연동되지 않으면 단순한 "소유권 주장"
* 메타데이터가 중앙 서버에 있으면 NFT는 껍데기
* 가격 투기 과열 → 거품 붕괴
* 저작권 침해 위험 (무단 발행 사례 존재)
* 사기, 피싱 사이트 등 보안 위협

---

## 🧠 한 줄 요약

> NFT는 **디지털 자산의 소유권을 온-chain으로 증명**하는 기술로, 예술, 게임, 커뮤니티를 혁신하지만, **투기와 실효성 논란**도 함께 안고 있음.

---

NFT를 직접 만들어보고 싶으시면 `Solidity`로 ERC-721 스마트컨트랙트를 작성하는 예제를 보여드릴 수 있어요. 아니면 NFT 기반 서비스(게임, 멤버십, 인증 등)의 기획도 도와드릴 수 있습니다. 원하시나요?
