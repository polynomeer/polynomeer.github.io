## 보충·교정 기준

- 무상태성과 연결 종료를 동일시하지 않음. HTTP/1.1 지속 연결은 RFC 9112와 대조.
- TCP 수신 확인과 애플리케이션 업무 성공을 구분.
- GET 본문, PATCH의 멱등성, 303·307·308, 401 챌린지의 의미를 구분.
- no-cache의 장애 시 재사용을 일반화하지 않음. RFC 9111의 현재 응답 지시어를 기준으로 설명.
- 캐시 기본값을 무조건 private로 서술하지 않음. no-store를 기존 캐시의 전역 삭제 수단으로 설명하지 않음.
- HttpOnly를 모든 XSS 방어로 설명하지 않음. SameSite와 단순 호스트 일치, 세션 쿠키와 브라우저 세션 복원을 구분.
- 영상 속 당시 출시 예정 강의나 재직 상태를 현재 사실로 옮기지 않음.
- 예제 HTTP 메시지는 설명용이며 브라우저·서버·CDN에서 실행한 결과로 제시하지 않음.
